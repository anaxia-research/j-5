# Only Maxwell Molecules Contract the Wasserstein Distance Among Power-Law Boltzmann Kernels with Cutoff

Deep Bhattacharjee

Tanaka's theorem says that two Boltzmann solutions never move apart in the quadratic Wasserstein distance when the molecules are Maxwellian. This paper proves that this fails for every other power law with angular cutoff, −3 < γ ≤ 2, for hard potentials without cutoff (including every inverse-power force), and for the Landau equation with hard potentials, answering Villani's question for these interactions.
